# 콘텐츠·편집·운영 설계

아래는 구현 요구와 권장 범위다. 2026-10-08 로컬 Next.js·Sanity Studio 연결 골격을 작성했다. 사용자 Sanity 프로젝트가 없어 실제 CMS 저장은 아직 검증하지 않았다. 실시간 미리보기·운영 공개 검증·문의 처리는 미구현이다. 실증 모델과 운영 모델은 구분한다.

## 데이터 구조

- 공통 프로젝트: ID, 주소, 분야 ID, 기간, 노출 순서, 홈 선정 여부.
- 공유 이미지: 원본, 크기·비율, 초점, 파생 이미지, 안정적인 asset ID.
- 언어별 프로젝트: 제목·요약·역할·대체 텍스트·검색 및 공유 문구·공개 상태.
- 공유 블록: 안정적인 ID, 종류, 순서, 이미지 참조, 폭·배치.
- 언어별 블록: 제목·본문·캡션·링크 문구·자유 HTML.
- 자유 코드: 공통 CSS, 필요 시 언어별 보정 CSS, 형식 버전.
- 수정 기록: 시점·수정자·언어·스냅샷. 초안과 공개본 분리.
- 공용 설정: 공개 이름, 연락처, 소개, UI 문구. 이름 미정.
- 테스트 데이터는 별도로 식별하고 실제 공개 데이터에 섞지 않는다.

## 기본 블록

| 종류 | 옵션 |
| --- | --- |
| 제목·본문 | 제목 단계·목록·강조·링크 |
| 이미지 | 본문/넓은/전체 폭, 전체 보기/채우기, 캡션 |
| 이미지 2열 | 동일 폭/2:1, 모바일 순서 |
| 이미지 모음 | 2~6개 자동 그리드·캡션 |
| 텍스트·이미지 | 좌우 및 모바일 읽기 순서 |
| 정보 목록 | 역할·범위·기간 등 이름과 값 |
| 구분·여백 | 작은/기본/큰 |
| 외부 링크 | 설명과 주소 |
| HTML·CSS | 코드·검증·모바일 미리보기 |

공통 블록은 정해진 디자인 옵션만 제공한다. 픽셀 단위 자유 조정은 기본 편집 흐름에 넣지 않는다. 복제·드래그·위아래 버튼을 제공한다.

## 자유 HTML·CSS

- iframe 별도 문서 격리를 우선 제안. CSS가 헤더나 다른 블록에 영향을 주면 안 된다.
- sandbox·보안 정책 적용, 사용자 JavaScript 및 이벤트 속성 실행 금지.
- HTML 문단·제목·목록·표·링크·승인 이미지, Flex/Grid·미디어 쿼리 지원.
- 외부 script/style import, javascript URL, 중첩 iframe, 자체 폼 제출 금지. 외부 리소스는 허용 목록 정책 정의.
- 공통 색·서체·간격·너비 변수를 별도 문서에 주입한다. 부모 CSS 변수를 자동 상속한다고 가정하지 않는다.
- HTML은 언어별 편집, CSS는 공유와 언어 보정 분리. 미디어 쿼리로 모바일 스타일 작성.
- 원본 HTML·CSS는 문자열로 저장. 줄바꿈·주석·들여쓰기 보존, 리치텍스트 변환·자동 포맷 금지.
- 원본과 렌더링용 검증 결과 분리. 금지 코드를 조용히 지우지 않고 공개 전 오류로 표시.
- 내보내기·불러오기·수정·복원에서 원본 보존 검증.
- 관리자가 작성한 코드는 신뢰 가능한 실행 코드로 간주하지 않는다.

실증 과제: sandbox 권한과 높이 측정의 양립, 이미지·폰트 로딩 후 높이, 중첩 스크롤 방지, 키보드 접근·스크린리더·검색 노출. 자동 높이 측정 또는 화면별 높이 옵션을 비교한다. 사용자 JS 없이 사이트 소유 코드로 측정하더라도 격리 권한을 약화시키지 않도록 설계를 검증한다. 자유 블록 외부로 넘치는 배치에는 한계가 있다.

## 편집 흐름

초안 생성 → 정보 → 이미지 → 블록 → 저장 → 인증된 미리보기 → 검증 → 언어별 공개 → 공개 반영 확인.

수정은 새 초안으로 진행하고 기존 공개본은 유지한다. 저장·공개·실제 반영 상태를 구분한다. 비공개 미리보기는 공개 API나 검색에 노출하지 않는다.

- 이미지: 원본 보존, 폭별 변환, WebP 등, 지연 로딩, 크기 예약, 대체 텍스트.
- 이력: 공개 시점 스냅샷·최근 저장, 이전 내용을 새 초안으로 복원. 서비스 기본 이력과 자체 구현을 구분.
- 파일 교체는 새 asset으로 처리해 이전 공개본을 보존. 미사용 파일 삭제 정책 별도.
- 백업: 콘텐츠와 실제 원본 파일 모두, 정기 별도 사본과 복원 시험.
- 내보내기: JSON + 원본 이미지 + asset 대응표 + 원본 코드 + schema 버전.
- 초기에는 예약 공개·다중 편집자·일괄 작업을 필수로 하지 않는다.

## 다국어

- 초기 `/ko/...` 권장, 한국어만 공개. 공개된 두 번째 언어가 있을 때 선택 메뉴 표시.
- 블록 순서·이미지는 공유하고 문구·캡션·대체 텍스트·HTML을 언어별 저장.
- 언어별 초안/검토 완료/공개. 원문 변경 시 번역 재검토 표시.
- 미번역 프로젝트는 해당 언어 목록에서 숨김. 직접 접근 시 준비 중 안내·한국어 원문 링크.
- UI 문구 별도 사전. 의도하지 않은 언어 fallback을 공개 화면에 노출하지 않는다.
- 영어 문구 확장, 고정 높이 제거, locale·검색 메타·언어별 URL 고려.

## 소개·문의

소개는 실제 경력, 맡을 수 있는 범위, 프로젝트 역할, 협업 방식을 중심으로 한다. 도구 나열·추상적 표현에 치우치지 않는다.

문의 필수: 이름/담당자, 회신 이메일, 내용, 개인정보 처리 동의. 선택: 회사/팀, 분야, 일정, 예산, 참고 링크. 일정·예산에 미정/상담 후 결정 제공.

검토용 문구: “기획·일정·예산이 모두 정해지지 않아도 괜찮습니다. 현재 생각하고 계신 내용을 알려주세요.” 해외 연락을 위해 “English inquiries are welcome.” 및 이메일·복사 제공.

- 문의 저장 성공 후 접수 완료. 알림 발송 실패는 재시도하고 저장 성공을 취소하지 않는다.
- 저장 실패 시 입력 유지·실패 안내·이메일 대안. 불확실한 결과에서 중복 제출 방지.
- 발송 접수와 실제 전달 상태 구분. 자동 회신이 실제 수신됐다고 단정하지 않는다.
- 서버 입력 검증·요청 제한·스팸 방지·비밀키 분리. 관리자 문의함 접근은 인증·권한 적용.
- 초기 첨부는 링크/이메일 후속 전달 권장. 필요 시 PDF/JPG/PNG, 최대 3개·합계 20MB 제안, 파일 검사·비공개 저장·만료 필요.
- 보관 기간, 삭제 정책, 개인정보 안내 및 처리 지역은 실제 서비스 선택 후 검토. 미확정 보관 정책을 운영 중인 것으로 표시하지 않는다.
