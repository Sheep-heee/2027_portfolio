# 1차 화면·디자인 설계

수치는 대표 화면 검토용 제안이며 최종 승인값이 아니다.

## 구조와 동선

- 홈: 큰 공개 이름 → 전문 분야 → 짧은 소개·작업 보기 → 대표 작업 → 어두운 업무 범위 영역 → 문의 안내.
- 목록: 큰 한글 제목 → 짧은 설명 → 텍스트 분야 필터 → 2열 이미지 목록 → 더 보기.
- 상세: 목록 복귀 → 제목·요약 → 분야·기간·역할 → 대표 이미지 → 본문 블록 → 다음 작업·문의.
- 소개: 전문 분야 → 실제 업무 범위 → 실제 경력 → 작업 방식 → 문의.
- 문의: 설명 → 폼 → 이메일 대안 → 처리 결과.
- 개인정보 안내와 비공개 관리자 별도. 이름·로고 클릭으로 홈 이동.
- 헤더: 이름 또는 텍스트 로고, 프로젝트 / 소개 / 문의. 모바일은 단정한 메뉴 패널.
- 의뢰자: 홈 → 분야 작업 → 상세 → 문의. 채용 담당자: 프로젝트 → 역할·기여 → 경력 → 연락.

공개 이름은 전역 설정에서 관리한다. 현재 `[공개 이름]` 검토용 표기를 사용한다. 이름 길이 변화로 헤더·홈이 깨지지 않도록 한다. 사진 없이 완성하고 추후 같은 텍스트로 사진형 전환을 준비한다.

## 프로젝트 목록 제안

- 전체 / 그래픽 / 웹 디자인 / UI·UX / 프론트엔드. 복수 분야 지정, 한 필터 선택 시 그 분야를 포함한 작업 표시.
- 4:3 이미지 프레임. 전체 보기 기본, 채우기와 초점 위치 선택 지원.
- 제목·분야·연도, 요약은 선택. 제목 생략 대신 줄바꿈. 설명이 없어도 카드 정렬 유지.
- 직접 노출 순서 우선, 미지정 작업은 프로젝트 날짜순. 동률은 안정적인 고유 ID 등으로 정렬.
- 최초 8개, 8개씩 버튼형 더 보기. 항목이 적으면 버튼 숨김. 필터와 복귀 상태 유지 방식은 구현 시 정의.
- 768px 미만 1열 제안. 이미지 크기 변화가 필요하면 정해진 패턴을 자동 적용하고 수동 레이아웃 작업을 요구하지 않는다.

## 색상·대비

| 농도 | 밝은 면 대비 | 어두운 면 대비 | 용도 |
| --- | --- | --- | --- |
| 100% | 9.97:1 | 9.97:1 | 제목·본문·주요 입력 |
| 80% | 5.66:1 | 7.05:1 | 작은 보조 정보·안내 |
| 50% | 2.63:1 | 3.79:1 | 장식, 작은 글씨 금지 |
| 20% | 1.42:1 | 1.76:1 | 장식 구분선 |
| 5% | 1.09:1 | 1.15:1 | 은은한 배경 |

두 지정 색상을 합성해 계산한 값이다. 작은 텍스트는 4.5:1 이상 목표. 조작에 필요한 테두리·포커스는 장식선과 구분해 충분한 대비 확보. 이미지 위 텍스트는 별도 검증. 색·배경·선에 알파를 적용하며 요소 전체 opacity는 사용하지 않는다. 오류는 텍스트·아이콘으로도 전달.

## 서체·크기 제안

- 한글·한영 혼용 문장: KoddiUD OnGothic. 문장 속 영문·숫자·괄호도 동일 서체.
- 독립 영문 이름·제목·영어 페이지: Montserrat. 한글 fallback은 KoddiUD 명시.
- 독립 연도·번호: Montserrat. 한글 문장 숫자: KoddiUD.
- 실제 배포 굵기만 사용, 인위적인 합성 굵기 금지. 공식 웹폰트를 우선 사용하고 변형·서브셋은 라이선스 확인 없이 하지 않는다.

| 요소 | 데스크톱 | 모바일 |
| --- | --- | --- |
| 한글 이름 | 96~144px Bold, 행간 1.1~1.2 | 56~72px, 1.15 |
| 페이지 제목 | 64~88px Bold, 1.2 | 36~48px, 1.3 |
| 섹션 제목 | 32~40px Bold, 1.4 | 26~32px |
| 카드 제목 | 24~28px Bold, 1.45 | 22~24px |
| 본문 | 18px Regular, 1.7 | 16~18px, 1.7 |
| 보조 정보 | 14~16px, 1.6 | 14~16px |
| 입력 | 16px 이상 | 16px 이상 |

실제 한글 내용과 공식 서체 활용 지침으로 다시 검토한다. 한글 제목을 영문과 같은 극단적인 자간으로 압축하지 않는다.

## 그리드·동작

- 최대 너비 1440px, 데스크톱 좌우 48~80px, 모바일 20~24px.
- 프로젝트 열 간격 24~40px, 읽기 본문 폭 680~760px.
- 8px 기반 간격. 섹션 간격 데스크톱 96~160px, 모바일 64~96px.
- 밑줄·선·배경 중심 150~200ms 전환. 과한 확대·등장 효과 금지.
- 키보드 포커스, 메뉴 포커스 관리·Escape 닫기, 감소된 모션, 최소 44px 조작 영역.
- 고정 높이 텍스트 박스 금지. 긴 영문·한글과 확대 보기에서 재배치.

## 대표 화면 검토

홈 첫 화면, 목록, 상세 일부, 문의를 데스크톱·모바일로 검토한다. 테스트 데이터임을 명시한다.

- 40~60자 한글 제목, 긴 영문 제목, 짧고 긴 공개 이름.
- 요약 없음, 복수 분야, 홀수 항목, 필터 결과 없음.
- 가로·세로·정사각 이미지, 긴 웹 캡처.
- 기본·자유 블록 연속 배치, 문의 오류·알림 실패.
- 360 / 390 / 768 / 1440px, 확대·키보드 이동.

테스트 3건: 긴 제목의 웹·UI/UX, 설명 적은 그래픽, 디자인·프론트엔드 복합. 중립 도형과 비율 안내로 이미지를 구성하며 가상 고객·성과를 넣지 않는다.
