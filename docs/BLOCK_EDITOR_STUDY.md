# 블록 편집 실증 · 2단계

2026-10-01. 대표 화면·서체는 사용자 최종 확인 완료. CMS·운영 구성은 미확정이며 이 화면은 전체 관리자 구현이 아니다.

## 열기

`node prototype/server.cjs` 실행 후 http://127.0.0.1:4173/editor.html . 브라우저 저장소를 사용하는 로컬 검토 화면이다.

## 범위

- 프로젝트 제목·요약 편집.
- 제목·본문, 이미지, 이미지 2열, 정보 목록, 구분·여백, 외부 링크 6종 추가·편집.
- 선택 블록 복제 (새 ID), 원본·복제본 독립 수정.
- 위·아래 버튼, 드래그로 순서 변경.
- 삭제와 최근 30회 변경 되돌리기. 이력은 세션 내 메모리이며 새로고침 시 초기화.
- 본문 읽기 폭·넓은 폭, 앞뒤 간격 옵션. 이미지 원본 유지·4:3 채우기.
- 360/390/768/1440px 미리보기. 편집 데이터를 postMessage로 전송하고 공통 서체·색상 규칙으로 렌더링.
- 명시적인 브라우저 저장과 새로고침 복원. 저장 실패는 성공으로 표시하지 않음.

## 사용 흐름

블록 추가 → 목록에서 선택 → 내용·옵션 수정 → 복제·위아래 이동 → 화면 너비 변경 → 브라우저에 저장 → 새로고침 복원.

저장은 localStorage `portfolio-block-study-v1`에 JSON으로 기록한다. 다른 브라우저·기기와 공유하지 않으며 저장소 삭제 시 사라진다. 아직 CMS 저장·공개본·권한·백업·다국어·원본 이미지 업로드 기능은 없다. 검토 이미지 세 개만 선택 가능하다. 실제 고객 자료를 입력하지 않는다.

## 코드 경계

- `block-model.mjs`: 블록 생성·복제·이동·저장 구조 검증.
- `editor.mjs`: 선택·필드·이력·저장·미리보기 메시지.
- `editor-preview.mjs`: 별도 문서에서 DOM을 구성, 입력은 textContent로 표시. HTML 입력을 실행하지 않음.
- `editor.css`: 관리자 검토 화면만의 배치. `styles.css`의 토큰·폰트 재사용.
- 미리보기 메시지는 동일 origin·지정 iframe/parent만 허용. 이는 자유 HTML 격리 검증을 대신하지 않음.

## 검증 기록

- 순수 모델 테스트 4건 통과: 독립 복제, ID·내용 보존 이동, 줄바꿈·순서 JSON 왕복, 손상 저장 형식 거절.
- 브라우저에서 텍스트 수정 → 복제본 수정 → 위로 이동 확인. 원본 내용 유지, 미리보기 순서 일치.
- 삭제 후 되돌리기로 블록 수 복원 확인.
- 정보·여백·링크 추가, 저장 → 새로고침 후 7개 블록과 수정 내용 유지 확인.
- 모바일 390px 미리보기에서 이미지 2열이 1열로 재배치 확인.
- 편집 화면 390/920/1440px에서 가로 넘침 없음, 콘솔 오류 없음 확인.
- 드래그 이동 코드는 추가했으나 위·아래 버튼과 달리 실제 브라우저 드래그의 동작 검증은 아직 남음.
- 저장 공간 부족·저장 차단 UI 분기는 있으나 브라우저 장애 주입 검증은 아직 하지 않음.

## 다음 단계

사용자가 편집 흐름을 검토한 뒤 3단계 자유 HTML·CSS의 원문 저장 왕복, 스타일 격리, 모바일 높이를 실증한다. 그 이후 CMS·운영 구성을 선택하고 전체 구현에 착수한다. 이 실증물의 localStorage·메모리 이력을 운영 CMS로 그대로 확장하지 않는다.
