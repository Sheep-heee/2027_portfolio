- 요구사항·첨부 해석을 바탕으로 1차 설계안을 대화에서 제시.

- 기술 선택·서비스 가입·결제·환경변수·도메인·배포.

## 다음 작업 순서

1. 홈 첫 화면·목록·상세·문의의 데스크톱/모바일 대표 화면 작성. 테스트 데이터 명시.
2. 이름 길이·긴 제목·요약 없음·가로/세로 이미지·반응형을 사용자와 검토.
3. 프로젝트 한 건의 블록 편집·미리보기·공개 흐름, 자유 코드 보존·격리·높이, 언어 구조 실증.
4. 실제 편집 경험과 비용·운영 부담으로 기술 선택.
5. 전체 구현 → 실제 콘텐츠 → 접근성·문의·검색 검증.
6. 공개 승인·도메인·발송 확인 → 백업 복구 시험 → 운영 인수.

현재 요청은 문서 생성이다. 다음 단계 전체 구현을 이번 요청에 포함된 것으로 해석하지 않는다.
