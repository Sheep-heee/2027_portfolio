## 2026-10-08 미리보기 출처 오류 수정

동일 비밀 값으로 localhost는 303, 127.0.0.1은 403 요청 출처 오류 재현. Next 개발 서버가 request.url을 localhost로 정규화하는데 브라우저 Origin과 직접 비교하던 것이 원인. POST 인증에서 실제 Host를 기준으로 출처 검사·redirect를 구성하고 임의 forwarded-host는 사용하지 않는다. 두 주소에서 정상 인증 303 및 접속 호스트 유지, 외부 Origin은 403 확인. 타입 검사 통과. Worker 빌드 재검증은 이번 수정 후 수행하지 않았다.
