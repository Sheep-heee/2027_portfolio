# 현재 상태

마지막 갱신: 2026-10-01 (Asia/Seoul)

## 실제 완료

- 요구사항·첨부 해석을 바탕으로 1차 설계안을 대화에서 제시.
- 사용자 후속 답변 반영: 이름 미정, 제안 비용 수준 허용, 테스트 데이터 사용, 직접 코드 수정 지원.
- 루트 AGENTS.md·README 및 설계·운영·코드·기술·상태 문서 생성.
- 사용자 Git 초기 설정 확인, 지침 재작성·큰 코드 변경의 버전관리 규칙 반영.
- 홈·목록·상세·문의의 독립 반응형 시안, 화면 비교 페이지, 테스트 프로젝트 3건, 실제 로컬 폰트 구성.
- 코드 구조 명세 작성. 전체 앱과 시안의 경계, 콘텐츠 모델·서비스 책임 기록.
- 네 화면 × 네 너비의 가로 넘침·열 배치, 필터·메뉴·문의 결과 시연 검증. 상세는 `docs/PROTOTYPE_REVIEW.md` 참고.

## 아직 하지 않은 일

- 대표 화면 사용자 디자인 검토 및 승인.
- 전체 앱 구현, CMS 실증, 자유 코드 저장·검증·자동 높이 실증.
- 기술 선택·서비스 가입·결제·환경변수·도메인·배포.
- 실제 콘텐츠 등록, 문의 처리, 백업·복원 검증.

## 다음 작업 순서

1. `prototype/review.html`의 대표 화면을 사용자와 검토.
2. 이름 길이·긴 제목·요약 없음·가로/세로 이미지·반응형에 관한 피드백 반영.
3. 프로젝트 한 건의 블록 편집·미리보기·공개 흐름, 자유 코드 보존·격리·높이, 언어 구조 실증.
4. 실제 편집 경험과 비용·운영 부담으로 기술 선택.
5. 전체 구현 → 실제 콘텐츠 → 접근성·문의·검색 검증.
6. 공개 승인·도메인·발송 확인 → 백업 복구 시험 → 운영 인수.

현재 요청은 대표 시안과 코드 구조 명세 작성이다. 다음 단계 전체 구현을 이번 요청에 포함된 것으로 해석하지 않는다.
