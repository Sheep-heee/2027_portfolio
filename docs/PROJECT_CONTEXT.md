# 프로젝트 맥락과 결정 상태

기준일: 2026-10-01 (Asia/Seoul)

## 목적과 운영자

- 국내외 외주 문의 확보가 주목적이며 채용 담당자의 역량·경력 확인도 지원한다.
- 사용자는 그래픽·웹·UI/UX 디자인과 프론트엔드 작업을 한다.
- AI가 개발하고, 사용자가 브라우저에서 콘텐츠를 등록·수정한다.
- 사용자는 개발이 가능하며 사이트 코드를 직접 커스텀할 계획이다.
- 월 비용은 허용하되 유지관리 부담과 서비스 수를 줄인다.
- 초기 한국어 공개, 이후 영어 등 언어 추가를 준비한다.

## 사용자 확정 조건

- 절제된 디자인 스튜디오 스타일. 큰 타이포그래피, 얇은 선, 정돈된 그리드, 넓은 여백, 큰 작업 이미지.
- 배경 `#EFEEF3`, 텍스트 `#353A3D`. 중요 섹션은 두 색을 반전한다. 추가 포인트 컬러 없음.
- 한글 KoddiUD OnGothic, 영문 Montserrat.
- 내비게이션은 상단 헤더. 우측 사이드바 없음.
- 홈 첫 화면은 이름·분야·소개만으로 완성. 빈 사진 자리나 임시 인물 사진 없음. 미래 사진형에서도 텍스트 재사용.
- 데스크톱 프로젝트 목록은 2열, 분야 필터 제공. 모바일은 가독성에 맞춰 재배치.
- 상세는 블록 추가·순서 변경 방식. HTML·CSS 자유 블록 필수, CSS 격리, 공통 변수, 모바일 CSS 지원. JavaScript 요구 없음.
- 구조·이미지를 재사용하는 다국어 콘텐츠, 언어별 HTML 편집, 공개 상태 지원. 미준비 언어 메뉴 숨김.
- 소개는 실제 경력·역할·업무 범위·작업 방식 중심. 문의는 계획·일정·예산이 미정이어도 가능.
- 문의 성공·실패는 실제 처리 결과에 따라 표시.
- 경력·고객 후기·프로젝트 성과·수치를 창작하지 않는다.
- 전체 구현보다 설계와 대표 화면 검토를 먼저 진행한다.

## 후속 답변으로 확정된 사항

- 공개 이름은 고민 중이다. 실명 또는 스튜디오·회사형 명칭을 비교 중이며 사업자등록은 아직 없다.
- 제안된 월 운영비 수준은 허용한다. 이것은 특정 서비스 선택·결제 승인이 아니다.
- 공개 가능한 프로젝트 2~3건은 있으나 자료가 미정리 상태다. placeholder 테스트 데이터로 먼저 검토한다.
- 직접 코드 수정이 가능하도록 코드 작성 규칙과 인수 지침을 작성한다.

## 제안이며 아직 확정되지 않은 사항

- 홈 / 프로젝트 / 소개 / 문의 구성, 초기 기록 페이지 제외.
- 필터: 전체 / 그래픽 / 웹 디자인 / UI·UX / 프론트엔드.
- 썸네일 4:3, 직접 정렬, 최초 8개와 8개씩 더 보기.
- Next.js + Sanity Growth + Vercel Pro + Resend 우선 검토.
- CSS Modules, TypeScript strict 등 구체 기술은 채택 시 적용할 코드 규칙 제안.
- iframe 기반 자유 블록 격리, 문의 첨부 초기 제외.

## 미정·후속 확인

- 공개 이름, 영문 표기, 연락 이메일, 도메인.
- 실제 경력·업무 세부 범위·프로젝트 자료와 공개 권한.
- 기술·서비스, 관리자 인증, 백업 저장소 및 유지관리 책임.
- 비공개 고객 자료의 보관 필요, 문의 첨부 필요, 개인정보 보관 기간.
- 실제 콘텐츠 기준 대표 화면의 최종 디자인.
