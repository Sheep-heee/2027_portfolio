# 자유 HTML·CSS 실증 (2026-10-01)

현재 범위는 로컬 편집 실증이다. CMS·공개 배포·서버 저장은 미구현이다.

## 사용 방법

http://127.0.0.1:4173/editor.html 에서 자유 HTML·CSS 블록을 추가한다. HTML과 CSS 원본을 편집하고 화면 너비를 바꾼다. 저장 후 새로고침하면 이 브라우저에서 복원된다. 기존 복제·이동·삭제·되돌리기를 동일하게 사용한다.

## 저장과 렌더링

모델에 html/css 문자열을 그대로 보관한다. JSON 저장 왕복에서 주석·공백·줄바꿈을 유지한다. 렌더용 DOM 직렬화·이미지 절대 경로 변경은 원본에 반영하지 않는다. 지원 범위 밖 코드도 초안 저장은 가능하며 미리보기는 이유를 표시하고 중지한다. CSS 파서는 잘못된 선언을 무시할 수 있으므로 모든 문법 오류를 진단하는 편집기는 아니다.

## 지원 범위와 격리

제목·본문·구획·목록·표·이미지·링크·details/summary를 지원한다. 클래스·ID·대체 텍스트·ARIA 등을 허용한다. 이미지는 제공된 테스트 SVG 3개만 지원한다. 링크는 http/https이며 실증 화면에서는 이동을 막는다. script·이벤트 속성·폼·중첩 iframe·style 태그·인라인 style·외부 CSS/폰트·CSS url()·CSS 이스케이프는 지원하지 않는다. 실제 업로드 이미지와 허용 자산 정책은 전체 구현에서 확장한다.

각 자유 블록은 allow-same-origin 없는 sandbox iframe이다. 사용자 CSS는 헤더나 다른 블록으로 나갈 수 없다. allow-scripts는 사이트가 주입한 자동 높이 브리지에만 필요하며, nonce CSP와 HTML 검증으로 사용자 JavaScript를 허용하지 않는다. 네트워크 기본 차단, 이미지·폰트는 로컬 서버만 허용한다. 공개 구현에서는 서버 검증과 보안 검토가 추가로 필요하다.

공통 --bg/--ink/--muted/--line/--wash, --font-ko/--font-ko-bold/--font-ko-extra/--font-en, --space를 전달한다. 16px=1rem과 Koddi 파일별 패밀리를 적용한다. 모바일 @media 작성 가능. 자유 코드 작성자도 Bold 크기 제한을 지켜야 한다.

높이는 ResizeObserver·폰트 완료·이미지 로드로 재계산한다. 메시지는 frame window·opaque origin·랜덤 토큰을 모두 검사한다. 최대 1250rem으로 제한한다. 콘텐츠는 정상 흐름으로 작성해야 하며 fixed/absolute만으로 구성하거나 뷰포트 높이에 의존하는 레이아웃은 자동 높이를 보장하지 않는다.

## 실제 검증

- 모델 테스트 5건 통과: 기본 블록과 자유 코드 JSON 왕복·독립 복제.
- 브라우저 저장/새로고침: HTML 주석·줄바꿈, CSS 주석·모바일 규칙 원본 일치.
- 자유 CSS의 h1/header 색상 변경에도 외부 상세 제목은 rgb(53,58,61) 유지.
- script 입력과 CSS @import 입력은 미리보기 중지 안내 확인.
- 1440/390 너비에서 내부 2열/1열 확인. iframe 실제 폭 1295/327px, 자동 높이 786/602px로 갱신 확인(폰트 로드와 측정 시점에 따라 값은 달라짐).
- 아직 악성 입력 전체 조합·다른 브라우저·실제 CMS 저장·백업 복원은 검증하지 않았다.
